Liquidgram для iPhone — установка через Sideloadly

Что понадобится:
- компьютер с Windows 10 или 11;
- iPhone с iOS 16 или новее и кабель USB;
- Apple ID. Лучше завести отдельный, а не входить основным:
  Sideloadly и сертификат разработчика будут привязаны к нему;
- файл Liquidgram.ipa.

1. Скачайте Liquidgram.ipa
   На GitHub откройте свой репозиторий → Releases → «Liquidgram for iPhone»
   (тег ios-latest) → Liquidgram.ipa.
   Если релиза ещё нет, откройте Actions → «Build iOS app» → Run workflow
   и подождите 15–20 минут. Готовый файл появится в релизе, а также
   внизу страницы сборки в разделе Artifacts (архив Liquidgram-iOS,
   внутри него Liquidgram.ipa).

2. Установите программы на Windows
   - Sideloadly: https://sideloadly.io (кнопка Download, версия для Windows).
   - iTunes с сайта Apple (https://www.apple.com/itunes/, не версию
     из Microsoft Store) или приложение «Устройства Apple»
     (Apple Devices) из Microsoft Store. Они ставят драйверы,
     без которых Sideloadly не увидит iPhone.
   - Если Sideloadly попросит iCloud для Windows, поставьте и его
     с сайта Apple.

3. Подключите iPhone кабелем, разблокируйте его и нажмите
   «Доверять этому компьютеру», затем введите код-пароль iPhone.

4. Установите приложение
   - Запустите Sideloadly и выберите свой iPhone в поле iDevice.
   - Перетащите Liquidgram.ipa в окно Sideloadly.
   - В поле Apple account введите Apple ID и нажмите Start.
   - Введите пароль Apple ID и, если попросят, код двухфакторной проверки.
   Sideloadly подпишет приложение вашим Apple ID и установит его на iPhone.

5. Включите режим разработчика (нужно один раз)
   На iPhone: Настройки → Конфиденциальность и безопасность →
   Режим разработчика → включить. iPhone попросит перезагрузиться;
   после перезагрузки подтвердите включение.
   Пункт «Режим разработчика» появляется после первой установки через Sideloadly.

6. Разрешите запуск приложений вашего Apple ID (нужно один раз)
   Настройки → Основные → VPN и управление устройством →
   ваш Apple ID в разделе «Приложение разработчика» →
   «Доверять …» → «Доверять».

7. Первый запуск
   Откройте Liquidgram. Первый экран на английском просит API ID и API hash:
   - войдите на https://my.telegram.org своим номером Telegram;
   - откройте API development tools и создайте приложение
     (название любое, платформа Web);
   - перепишите api_id и api_hash в Liquidgram и нажмите Continue.
   Затем войдите в Telegram по номеру телефона, как обычно.
   Когда приложение спросит про уведомления, разрешите их, если хотите
   получать уведомления о сообщениях, пока Liquidgram открыт.

Каждые 7 дней
   С бесплатным Apple ID подпись действует 7 дней. Потом приложение
   перестаёт открываться, но его данные не пропадают.
   Чтобы продлить, снова установите тот же Liquidgram.ipa через Sideloadly
   тем же Apple ID: переписка, ключи и настройки сохранятся.
   Sideloadly умеет продлевать сам: включите в нём автоматическое
   обновление (Auto Refresh), оставьте Sideloadly запущенным, а компьютер
   и iPhone — в одной сети Wi-Fi. Для этого один раз включите в iTunes
   или «Устройствах Apple» синхронизацию iPhone по Wi-Fi.

Если Sideloadly пишет, что идентификатор приложения (bundle ID) занят
   Откройте Advanced options и отметьте Change bundle ID: Sideloadly
   подставит свой идентификатор. При следующих установках используйте
   тот же идентификатор. С другим идентификатором iPhone поставит второе
   приложение с пустыми данными, и входить придётся заново. Пока
   идентификатор и Apple ID те же, данные сохраняются при каждой переподписи.

Обновление
   Установите новый Liquidgram.ipa через Sideloadly тем же Apple ID и с тем же
   идентификатором приложения. Данные сохранятся.

Ограничения
   - С бесплатным Apple ID можно держать установленными не больше трёх
     приложений, поставленных так, и создавать до 10 идентификаторов
     приложений за 7 дней.
   - Уведомления приходят, пока Liquidgram открыт или только что свёрнут.
     Пуш-уведомлений при закрытом приложении нет: бесплатная подпись
     их не поддерживает.
   - Видео и большие файлы сначала скачиваются целиком.
   - Удаление приложения стирает его данные: после переустановки
     придётся снова ввести ключи и войти в Telegram.
