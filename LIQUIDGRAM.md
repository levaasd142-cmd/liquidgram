# Liquidgram 💧

Неофициальный клиент Telegram на базе [Telegram Web A](https://github.com/Ajaxy/telegram-tt) (GPL-3.0) с дизайном **Liquid Glass** в стиле iOS 26 и набором приватных фич. Работает в браузере, ставится на iPhone и Android как приложение (PWA): «Поделиться» → «На экран „Домой“».

## Что добавлено

### Дизайн Liquid Glass
- Стеклянные панели, плавающая шапка чата, поле ввода и меню: размытие, насыщенность, блики по краям.
- **Преломление света** по краям стекла: SVG-фильтр с картой смещения, работает в Chrome и Edge (Safari и Firefox показывают обычное матовое стекло).
- Ползунок силы эффекта стекла, тёмная и светлая темы.
- Пастельный градиентный фон по умолчанию и лавандовые исходящие сообщения.
- Плавающий стеклянный таббар «Чаты / Контакты / Настройки» на телефонах.
- Свой логотип, иконки PWA и название.

### Режим призрака 👻
Быстро включается кнопкой с глазом рядом с поиском. Настраивается по пунктам:
- не отправлять «прочитано»;
- не показывать «печатает…»;
- всегда быть офлайн;
- смотреть истории анонимно;
- не отмечать голосовые и кружки прослушанными;
- отмечать чат прочитанным, когда отвечаешь (чтобы ответ не выглядел странно).

### Сообщения
- **Антиудаление**: сообщения, которые удалил собеседник, остаются у тебя с красной пометкой «удалено» и сохраняются после перезагрузки. Сообщения, которые ты удаляешь в Liquidgram, удаляются как обычно, а очистка истории чата стирает и сохранённые копии. Самоуничтожающиеся медиа и сообщения с автоудалением не сохраняются. Удаления с других твоих устройств клиент не отличает от чужих, поэтому они тоже сохраняются.
- **История правок**: нажми на «изменено», и под сообщением появятся его прошлые версии.
- Секунды во времени сообщений.

### Интерфейс
- **Режим стримера**: размывает переписку, имена и аватарки, пока не наведёшь курсор.
- ID пользователей и чатов в профиле, по нажатию копируется.
- Скрытие историй.
- «Прочитать все чаты» одной кнопкой.

Все переключатели лежат в **Настройки → Liquidgram**.

## API-ключи

Неофициальному клиенту нужны собственные `api_id` и `api_hash`:

1. Войди на <https://my.telegram.org> → **API development tools**.
2. Создай приложение (название любое, платформа Web).
3. Ключи можно:
   - вписать в `.env` перед сборкой (`TELEGRAM_API_ID`, `TELEGRAM_API_HASH`), или
   - ничего не указывать: тогда Liquidgram сам спросит их на экране входа и запомнит в браузере. Если Telegram отклонит ключи, форма появится снова.

## Сборка

Нужен Node.js 24+.

```bash
npm ci
npm run build:production
```

Готовый сайт появится в папке `dist/`. Это статические файлы: их можно выложить на GitHub Pages, Vercel, Netlify, Cloudflare Pages или любой хостинг. Для проверки локально:

```bash
npx serve dist
```

Режим разработки с автообновлением: `npm run dev` → <http://localhost:1234>.

## Расширение для браузера

```bash
npm run build:extension
```

Готовое расширение для Chrome, Edge, Яндекс Браузера, Brave и Opera появится в папке `dist-extension/`. Установка: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка `dist-extension`. Иконка расширения открывает Liquidgram во вкладке или в боковой панели.

Поле `key` в `extension/manifest.json` закрепляет ID расширения, поэтому после обновления или переноса папки вход и настройки сохраняются.

Ограничения расширения:

- Сервис-воркер на страницах расширения выключен, поэтому видео не стримится, а скачивается целиком перед воспроизведением, и уведомления приходят, только пока Liquidgram открыт во вкладке или в боковой панели.
- В боковой панели браузер не показывает запросы разрешений: микрофон нужно один раз разрешить во вкладке.
- Без «Режима разработчика» браузер отключает распакованное расширение.

## Приложение для Windows

```bash
npm run build:desktop
```

Нужны Go 1.24+ и NSIS. Готовые файлы появятся в `dist-desktop/`: установщик `Liquidgram-Setup.exe`, переносная версия `Liquidgram-Portable.zip` и Linux-версия того же лаунчера. Подробности — в [desktop/README.md](desktop/README.md).

Лаунчер на Go содержит веб-сборку внутри себя, отдаёт её на `127.0.0.1` с постоянным портом и открывает окно Microsoft Edge или Chrome в режиме приложения, с отдельным профилем и без адресной строки. Сервис-воркер работает, поэтому видео стримится. Установщик ставит Liquidgram без прав администратора и создаёт ярлыки.

Ограничения: программа не подписана, поэтому Windows SmartScreen предупреждает при первом запуске; нужен Edge или Chrome; уведомления приходят, пока окно открыто.

## iPhone и Android

На телефоне Liquidgram ставится как веб-приложение на экран «Домой», для этого нужен HTTPS-адрес:

- **GitHub Pages.** Workflow [.github/workflows/pages.yml](.github/workflows/pages.yml) собирает и публикует сайт при пуше в основную ветку. Один раз включи Settings → Pages → Source: GitHub Actions.
- **Netlify Drop.** Перетащи папку со сборкой (без файлов `*.map`) на <https://app.netlify.com/drop> и сохрани сайт в бесплатный аккаунт.

Дальше на iPhone: открыть адрес в Safari → «Поделиться» → «На экран „Домой“». На Android: Chrome → «Установить приложение».

## Важно

- Это неофициальный клиент. Фичи вроде призрака и антиудаления работают только на твоём устройстве, но Telegram теоретически может не одобрять сторонние клиенты: используй на свой страх и риск.
- Лицензия GPL-3.0, как у оригинального Telegram Web A: исходники форка должны оставаться открытыми.
